# 🚀 OfferPilot 求职全景进度状态机与智能流转方案 (AI 原生严谨版)

## 💡 方案核心理念与业务闭环

本方案遵循最真实、最严谨的求职心理模型：  
**“桌面端打勾代表该场笔试/面试的参加完毕，整个公司的应聘进展则客观流转为【该环节已结束 · 等待本轮结果】。”**

* 绝不主观跨越流程（例如一面结束后是 **“等待一面结果”**，而非预设进入二面）；
* 只有当云端抓取到下一封邮件（如二面邀请或感谢信）时，流程才正式由客观事实推向下一里程碑。
